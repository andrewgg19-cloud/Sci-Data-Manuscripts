# El filtro también puede crear correlaciones 📊

Este repositorio contiene el código fuente en **LaTeX** y el modelo computacional en **Python** para el paper: *“El filtro también puede crear correlaciones: Un modelo computacional reproducible y sus implicaciones”*.

## 🎯 Resumen del Proyecto
Demostramos formalmente que condicionar los datos a través de una región de selección no factorizable induce inevitablemente una covarianza distinta de cero entre variables originalmente independientes. Este fenómeno es conocido como el **sesgo del colisionador** o la **Paradoja de Berkson**.

## 🔬 Estructura
* `paper.tex`: Documento en LaTeX con la demostración matemática formal.
* `simulacion.py`: Script en Python que ejecuta la simulación y genera el gráfico interactivo.
