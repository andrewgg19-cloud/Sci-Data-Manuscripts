## Scope

German Gamma v5.8 is an exploratory diagnostic for filter-induced structure.

It does not prove:

```text
fraud
intent
causality
experimental invalidity
```

It reports:

```text
support loss
selection-compatible signals
3D interaction diagnostics
energy-entropy changes
temporal sheet rarity
reversibility asymmetry
```

## Rule

Raw results come first. Regularization, when present, is auxiliary and labeled.
