# 10 - Easy Problem and Hard Problem Boundary

Purpose: separate what German Gamma can program from what it cannot claim.

## Easy Problem Layer

The easy problem concerns measurable functions:

```text
recognition
classification
comparison
memory reconstruction
transition detection
probability assignment
entropy change
reversibility analysis
```

These can be represented as data operations.

## Programmable Chain

```text
point -> centroid -> label -> sequence -> transition -> probability -> entropy
```

## Metrics

```text
recognition:
reconstruction_error

transition:
P(z_{t+1} | z_t)
transition_matrix
transition_entropy

memory/reconstruction:
reversibility_score
forward_reverse_divergence

uncertainty:
entropy
support_loss
empirical_probability
```

## Hard Problem Boundary

The hard problem concerns subjective experience:

```text
what it feels like
first-person awareness
qualia
subjective consciousness
```

German Gamma does not measure or prove this.

## Rule

```text
The easy problem can be programmed.
The hard problem must be bounded.
```

## Determination

Allowed:

```text
German Gamma measures structural recognition patterns.
German Gamma measures transitions and uncertainty.
German Gamma can model functional correlates of recognition.
```

Not allowed:

```text
German Gamma proves consciousness.
German Gamma generates subjective experience.
German Gamma solves the hard problem.
```

## Sentence

```text
German Gamma can program the easy problem of structural recognition; the hard
problem remains an explicit philosophical boundary outside the model's claims.
```
